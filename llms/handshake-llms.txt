# Handshake

> Handshake (joinhandshake.com) is the early-career talent network connecting students and recent graduates with employers, and the higher-education Career Services teams that support them. Its developer surface centers on the read-only, institution-scoped EDU API (currently in beta) for career-services data management and automation.

This llms.txt was generated by the API Evangelist enrichment pipeline from the public developer documentation and catalog metadata; the EDU API itself is partner-gated and publishes no public OpenAPI.

## APIs

- [Handshake EDU API — Getting Started](https://support.joinhandshake.com/hc/en-us/articles/31061076506391-Getting-Started-with-EDU-API): Read-only, institution-scoped API for career-services data (applications, appointments, career fairs, jobs, postings, qualifications, meetings). Auth via `x-api-key` header. Beta, gated to Career Services partners.
- [EDU API Endpoint Definitions](https://support.joinhandshake.com/hc/en-us/articles/35762729693719-EDU-API-Endpoint-Definitions): Resource/endpoint reference for the EDU API.
- [Developer Portal](https://edu-api.joinhandshake.com:444/): Subscriptions, API keys, and API explorer.
